# 04. NFC書き込み

公開URLを、配布されたNFCカードに書き込みます。
書き込むのはサイトのURLだけです。カードに個人情報そのものは入りません。

## 書き込むもの

GitHub Pages のURLです。`https://` から始まる形で書いてください。

```
https://<GitHubユーザー名>.github.io/nfc-web-card/
```

末尾の `/` は付けても付けなくても大丈夫です。書き込み後、カードはロックしないでください。URLをやり直せるようにしておきます。

## Android

1. Chrome で [web-nfc-app](https://web-nfc-app.illionillion.workers.dev/) を開く
2. 公開URLを入力する
3. 書き込みを開始し、カードを端末の背面に当てる
4. 成功表示が出たら離す

NFCが反応しにくいときは、カバーを外すか、端末背面の上寄りに当ててみてください。

## iPhone

1. [NFC Tools](https://apps.apple.com/app/nfc-tools/id1252962749) を開く
2. `Write`（書き込み）を選ぶ
3. `Add a record` から URL / URI を選ぶ
4. 公開URLを入力する
5. `Write` を押し、カードをiPhone上端付近に当てる

書き込みは、おおむね iPhone XS 以降でできます。書けない場合は、Androidを持っている人やサポートにURLを渡してください。

## 読み取り確認

書き込みが終わったら、別のスマホでも試します。

1. 画面ロックを解除する
2. カードに端末をかざす
3. 通知やバナーからサイトが開くことを確認する

iPhoneはコントロールセンターからNFCを探す必要はありません。ロック解除した状態でカードに近づければ読めます。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 反応しない | カードの位置をずらす。ケースを外す。別の端末で試す |
| 別のURLが開く | 以前の書き込みが残っている。もう一度URLレコードだけ書き込む |
| サイトが404 | GitHub Pages のURLをブラウザで直接開いて確認する |
| iPhoneで書けない | 機種が書き込み非対応のことがある。サポートに依頼する |

読めてサイトが開けたら完成です。カードを持って、自己紹介に使ってみてください。
