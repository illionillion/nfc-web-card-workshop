# 01. 事前準備

サイトを作り始める前に、手元の準備を済ませます。
この段階では、新しい GitHub リポジトリは作らなくて大丈夫です。

## 1. ZIPで入手する

1. 主催者が案内した GitHub のリポジトリページを開く
2. 緑色の `Code` を押す
3. `Download ZIP` を選ぶ
4. 解凍して、デスクトップなど分かりやすい場所に置く

フォルダ名は `nfc-web-card-workshop-main` のようになることがあります。そのままで問題ありません。

## 2. VS Code でフォルダを開く

1. Visual Studio Code を開く
2. `ファイル` → `フォルダーを開く`
3. 解凍したフォルダを選ぶ

作業するファイルは次の3つです。

- `starter/index.html`
- `starter/style.css`
- `starter/script.js`

写真を使う場合は `starter/assets/` に置きます。`docs/` は公開用の出力先なので、自分では編集しないでください。

## 3. 初期状態をブラウザで見る

`starter/index.html` をブラウザにドラッグするか、右クリックしてブラウザで開きます。

プレースホルダーの名刺が表示されれば準備完了です。完成例を見たいときは `examples/sample-card/index.html` も開いてください。

## 4. GitHubアカウント

公開のときに使います。まだなら [GitHub](https://github.com/signup) で作成してください。無料アカウントで十分です。

## 5. NFC書き込みアプリ

カードへの書き込みは後半です。通信が混み合う前に入れておくと安心です。

| 端末 | 使うもの |
| --- | --- |
| Android | 主催者ツール [web-nfc-app](https://web-nfc-app.illionillion.workers.dev/)（Chrome） |
| iPhone | [NFC Tools](https://apps.apple.com/app/nfc-tools/id1252962749) |

iPhone で書き込むには、おおむね iPhone XS 以降が必要です。読めない・書けないときはサポートに渡してください。
