# 公開前チェックプロンプト

公開前に、作った `starter/` のファイルを添付してこのプロンプトを使います。

```
このWeb名刺を GitHub Pages で公開し、NFCカードにURLを書き込みます。
確認対象は starter/ です。docs/ は見なくて大丈夫です。

見てほしいこと:
- 名前、自己紹介、リンクがプレースホルダーのままになっていないか
- 画像パスが相対パスになっているか（./assets/photo.jpg など）
- リンクに https:// が付いているか
- スマホ幅でも読めるか
- 載せてはいけない個人情報（住所、電話番号、社外秘）がないか

問題があれば starter/ への修正案を出してください。大きなリファクタはしないでください。
```
