# 要件定義プロンプト

VS Code の Copilot を使う場合は、このファイルを貼らずにチャットへ `/web-card` と打ってください。

Copilot 以外のAIチャットに、このまま貼り付けて使います。

```
私はNFCカード用の自己紹介Webサイト（Web名刺）を作ります。
実装はまだしないでください。先に要件だけを一緒に固めてください。

次の項目を、一度に全部ではなく会話形式で聞いてください。
公開したくない情報は載せません。住所や電話番号は提案しないでください。

- 載せる個人情報（名前、ふりがな、肩書き、所属、公開してよい連絡先）
- 写真を使うか。使うなら1枚か複数か（複数ならカルーセル）
- 自己紹介文（2〜4文と口調）
- アピールしたい実績（3つ前後）
- リンク（GitHub と X を最優先で確認。そのあとブログやメール）
- デザインの希望（雰囲気、色、ダーク/ライト、角丸、フォント）

最後に、決まった内容を次の形でまとめてください。

# Web名刺 要件
- 名前:
- 肩書き:
- キャッチコピー:
- 写真: （枚数とファイル名）
- 自己紹介:
- 実績:
- リンク: （GitHub / X を先に）
- デザイン:
```
